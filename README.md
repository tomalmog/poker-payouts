# Poker Payout Calculator

A simple and intuitive tool to calculate poker tournament payouts based on chip counts and buy-ins. Built with Next.js.

Keep track of your home game with ease! This calculator helps determine how much each player should win or lose based on their final chip stack, buy-ins, and custom chip denominations.

Perfect for friendly poker nights where players rebuy throughout the game.

Try it out here https://poker-payouts.vercel.app

---
## Features

- **Dynamic Player Management** – Add, remove, and edit players in real time.
- **Payout Calculation** – Automatically computes net profit/loss per player.
- **Custom Chip Denominations** – Define chip colors, values, and total starting stack.
- **Export to CSV** – Download the final leaderboard as a CSV file.
- **Save & Load Game State** – Persist your session using `localStorage`.
- **Responsive Design** – Works seamlessly on desktop and mobile devices.

---

## Tech Stack

- **Next.js 14** – React framework with App Router
- **React** – Component-based UI
- **Tailwind CSS** – Utility-first styling
- **Framer Motion** – Smooth animations
- **json-2-csv** – CSV export functionality
- **Lucide Icons** – Clean, modern icons
